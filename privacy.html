Gmail Connector privacy policy

Last updated 24 November 2026 · About Gmail Connector

Gmail Connector is a private, read-only tool. Its owner runs it on their own computer to read their own inboxes and chats. It is not offered to the public, and nobody else's account is connected to it.

What it reads

  • Gmail, with Google's read-only Gmail permission (gmail.readonly) and the account's email address. It reads messages, threads, labels and attachments of the inboxes the owner connects.
  • It cannot send, delete, label or change any email, and it never does.

How the data is used

  • To show the owner their own email when they ask for it (for example in Claude on their computer).
  • To build the owner's own daily inbox summary, which is emailed only to the owner.

The data is not sold, not used for advertising, and not shared with anyone except the services that carry out the two uses above for the owner: GitHub (storage) and Anthropic's Claude (reading and summarising).

Where it is stored

  • Sign-in tokens are stored encrypted on the owner's computer, and encrypted in the owner's private GitHub repository so the summary can be refreshed automatically.
  • A snapshot of the last 7 days of email (messages capped at 4,000 characters, promotions and social mail left out) is kept in the owner's private GitHub repository and replaced every 2 hours. Older copies are not kept.

Removing access

Access can be removed at any time in the app (Disconnect), or in the Google Account under Security → Third-party apps with account access. Disconnecting deletes the stored token.

Google API Services User Data Policy

Gmail Connector's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact
